CÓMO EJECUTAR
1. Extrae el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre index.html con la extensión Live Server (clic derecho > Open with Live Server), o abre index.html en tu navegador.
4. Para activar el juego, edita script.js y sustituye const GAME_URL = ''; por const GAME_URL = 'https://TU-ENLACE-REAL';
5. Para publicar la web, sube el contenido de esta carpeta a un servicio de hosting estático (por ejemplo GitHub Pages o Netlify).

Nota: Las fuentes tipográficas usan Google Fonts; sin internet se usan fuentes de respaldo.
